CSS Basics

CSS stands for Cascading Style Sheets.

CSS allows developers to style HTML elements using colours, fonts and layouts.

Responsive Design

Responsive design helps websites display correctly on different screen sizes.

Media queries allow CSS style to change based on the device's screen width.

    Mobile-friendly layouts
  • Flexible images
  • Media queries
  • Responsive typography
  • Flexible grids
@media (max-width: 600px) {body{font-size: 14px;}}
